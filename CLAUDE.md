# ITOMS Claude Repository Instructions

Read `REPO_START_HERE.md` before doing any repository work, then follow the complete mandatory read order listed there.

Canonical IDs are permanent. Names are mutable labels. Check the Object and Domain registries before introducing terminology, schema, relationships, screens, or workflows. Every first-class object belongs to exactly one Primary Domain. Use `PrimaryInternetDomain` only for Company DNS/Internet names.
